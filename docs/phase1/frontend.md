# Фаза 1. Фронт (FE)

Правила зависимостей и общая картина — [README](README.md). Цель фазы и точки стыковки — [спека 0003](../specs/0003-phase1-plan.md).

## Вводная

- **Читать:** [спека 0003](../specs/0003-phase1-plan.md), разделы CFC-1 (API) и CFC-4 (моки); [спека 0002](../specs/0002-visa-and-citizenship.md) (визы, статусы, новые эндпоинты); [`spec.md`](../spec.md), раздел 3.10 (интерфейс, дизайн-референс); `api/openapi.yaml` — источник правды по данным.
- **Стек:** React 19, TypeScript 7, Vite 8, Tailwind 4, shadcn/ui и Magic UI, MSW 3, openapi-typescript (через `npm run gen:api`).
- **Зона:** `web/`. В `cmd/`, `internal/`, `data/` не пишем.
- **Как не ждать бэкенд:** `cd web && npm ci && VITE_MOCKS=1 npm run dev` — моки MSW отдают полную поездку и проигрывают события хода. Весь план и вся вёрстка делаются на моках; живой бэкенд — только финальная проверка (`P1-FE-11`).
- **Типы:** только из `web/src/api/schema.ts`. Не хватает поля — это изменение контракта (README, правило 5), а не локальный тип.
- **Ветки:** до мержа PR #1 — от `phase0-contracts`, после — от `main`.
