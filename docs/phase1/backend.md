# Фаза 1. Бэкенд (BE)

Правила зависимостей и общая картина — [README](README.md). Цель фазы и точки стыковки — [спека 0003](../specs/0003-phase1-plan.md).

## Вводная

- **Читать:** [спека 0003](../specs/0003-phase1-plan.md) (CFC-1, CFC-2, CFC-3, CFC-5), [спека 0002](../specs/0002-visa-and-citizenship.md) (контракт виз), [ADR 0003](../adr/0003-visa-by-citizenship.md), ADR 0001 (граф этапов, гейты, валидатор).
- **Стек:** Go 1.27, Gin 1.12, gRPC 1.84, pgx v5, goose v3, NATS 2.15 (`nats.go` 1.55), `openai-go` v3, PostgreSQL 18; генерация proto — `scripts/gen-proto.sh` (protoc 36.2).
- **Зона:** `cmd/`, `internal/`, `migrations/`, `config/`, `deploy/`, реализации `proto/`. В `web/` и `data/` не пишем (кроме минимальной правки фикстуры в `P1-BE-01.4`, без которой не проходит CI фронта).
- **Как не ждать данные:** всё читаем из `DATA_DIR`. Пока роль DS не смержила наборы, работаем на своём тестовом снапшоте `internal/dataset/testdata/` в формате CFC-3. Подключение настоящих данных — отдельные короткие подзадачи в конце каждой задачи.
- **Ветки:** до мержа PR #1 — от `phase0-contracts`, после — от `main`.
