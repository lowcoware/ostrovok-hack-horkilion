# Фаза 1. Данные (DS)

Правила зависимостей и общая картина — [README](README.md). Цель фазы и точки стыковки — [спека 0003](../specs/0003-phase1-plan.md).

## Вводная

- **Читать:** [спека 0003](../specs/0003-phase1-plan.md), разделы CFC-3 (формат снапшота) и CFC-5 (калибровка); [спека 0002](../specs/0002-visa-and-citizenship.md), раздел «Файлы снапшота» и таблица статусов визы; [`spec.md`](../spec.md), раздел 6 (источники, лицензии, что генерируем).
- **Стек:** Python 3.12, стандартная библиотека и `requests`; сторонние библиотеки — только если без них загрузчик не написать, версии в `data/requirements.txt`.
- **Зона:** `data/`. Go-код и `web/` не трогаем.
- **От кого зависишь:** ни от кого. Формат файлов задан спекой 0003, бэкенд читает то, что ты положишь в `data/snapshot/`.
- **Кто ждёт тебя:** бэкенд, только на подключение. До твоих наборов он работает на своём тестовом снапшоте, после мержа — переключается на твой (README, «Межролевые зависимости»). Чем раньше смержены `02`, `03`, `04`, тем раньше агент начнёт работать на реальных направлениях.
- **Ветки:** от `main`.

## Что ты отдаёшь

| Набор | Подзадача | Кто читает |
|---|---|---|
| `countries.jsonl`, `visa.jsonl` | `02.1`, `02.2` | `catalog`: страны, визы, фильтр подбора |
| `cities.jsonl` | `04.1` | `catalog`: город отправления, привязка направлений |
| `airports.jsonl` | `04.2` | `transport`: авиа |
| `destinations.jsonl`, `climate.jsonl` | `03.1`–`03.4` | `catalog`: подбор и погода |
| `hotels.jsonl` | `05.1`, `05.2` | `lodging` провайдер `osm` |
| `routes.jsonl`, `stations.jsonl`, `rail_routes.jsonl` | `06.1`–`06.3` | `transport` |
| `calibration.jsonl` | `07.1`–`07.6` | синтетические цены всех провайдеров |
| `sources.yaml` | `01.4`, `08.1` | страница «Откуда данные» |

Обязательное для каждого набора: схема из CFC-3, стабильный `id`, `sources` с именами из `sources.yaml`, запись в `manifest.json`, `python3 data/validate.py` проходит.

## Задачи

### P1-DS-01. Каркас `data/`

| Подзадача | Что | Зависит от | Готово, когда |
|---|---|---|---|
| `01.1` | раскладка каталогов из CFC-3, `requirements.txt` | — | структура в `main` |
| `01.2` | `build.py`: собирает `snapshot/` из `loaders/` и `overrides/`, пишет `manifest.json` с `records` и `sha256` | `01.1` | повторный запуск без изменений даёт тот же `sha256` |
| `01.3` | `validate.py`: схемы всех наборов CFC-3, дубли `id`, неизвестные имена в `sources`; запуск в CI при изменении `data/` | `01.2` | на сломанном файле падает с номером строки и полем |
| `01.4` | `sources.yaml` со всеми источниками из `spec.md`, раздел 6, поля из CFC-3 | `01.1` | каждый источник раздела 6 есть в реестре |

### P1-DS-02. Страны и визы

| Подзадача | Что | Зависит от | Готово, когда |
|---|---|---|---|
| `02.1` | `countries`: ISO-коды, названия по-русски и по-английски | `01.2` | все страны из визовой матрицы есть в `countries` |
| `02.2` | `visa`: вся матрица `imorte/passport-index-data` (199 паспортов), перевод статусов по таблице спеки 0002 | `02.1` | пара есть для каждого паспорта и каждой страны каталога |
| `02.3` | сверка с whereTOemigrate: отчёт расхождений в `data/reports/visa-diff.md` | `02.2` | отчёт в `main`, расхождения по паспорту РФ разобраны |
| `02.4` | сверка паспорта РФ со справкой Консульского департамента МИД по странам каталога, правки в `overrides/visa.csv`, у сверенных записей источник `mid-ru` | `02.2`, `03.1` | все страны каталога для паспорта РФ сверены |

### P1-DS-07. Калибровка синтетики

Один объект `calibration` (CFC-3), у каждого параметра — источник.

| Подзадача | Что | Зависит от | Готово, когда |
|---|---|---|---|
| `07.1` | цена за место по звёздам: Росстат для России, уровень цен для каждой страны каталога | `03.1` | для каждой страны каталога есть уровень цен |
| `07.2` | сезонные коэффициенты: Hotel Booking Demand, праздники Nager.Date | — | коэффициент для каждого месяца |
| `07.3` | уровень цен на авиабилеты за км: Aviasales Data API | — | цена за км для коротких и длинных перелётов |
| `07.4` | тарифы такси и шаттла, надбавка за животное | — | тарифы для городов каталога или общий с коэффициентом города |
| `07.5` | курсы ЦБ РФ на дату снапшота для валют стран каталога | `03.1` | курс есть для каждой валюты каталога |
| `07.6` | туристический налог по городам России | `03.1` | ставка для каждого российского направления, где налог введён |
